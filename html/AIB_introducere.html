Fie următoarea problemă:

Se dă un vector v (indexat de la 1) care conține n elemente, după care se dau m operații care pot fi de 2 tipuri:
A) Adaugă val la v[pos]; (Actualizare)
B) Afișeaza suma subsecvenței [pos1, pos2] a vectorului; (Interogare)

O soluție constă în crearea unui vector suplimentar de sume parțiale pentru răspuns în O(1) la interogare. Problema cu această abordare este că prima operație implică actualizarea a n - pos poziții din vectorul de sume parțiale, ceea ce poate duce la O(n), deci o complexitate totală de O(n*m). Tot aceeași complexitate obținem dacă renunțăm la sume parțiale pentru a actualiza în O(1) și răspundem prin iterare în O(n) la a 2-a operație. Pentru o soluție optimă de O(mlog n) vom putea folosi un AIB.

Ideea din spate

Un Arbore Indexat Binar (AIB pe scurt) este o structură de date dinamică, eficientă, ușor de implementat, care ocupă puțin spațiu și implementează în timp logaritmic actualizarea și interogarea pe un prefix/sufix. Acesta funcționeaza după urmatorul principiu:

1. AIB[i] = v[i] dacă i = M1, i ≠ M2
2. AIB[i] = v[i-1] + v[i] dacă i=M2, i ≠ M4
3. AIB[i] = v[i-3] + v[i-2] + v[i-1] + v[i] dacă i = M4, i ≠ M8
4. AIB[i] = v[i-7] + v[i-6] + v[i-5] + v[i-4] + v[i-3] + v[i-2] + v[i-1] + v[i] dacă i = M8, i ≠ M16
...
k. AIB[i] = v[i - 2(k-1) + 1] + ... + v[i-1] + v[i] dacă i = M2(k-1), i ≠ M2k

Calculați: AIB[] = Σ(17, 24);

Cu alte cuvinte, AIB[i] stochează suma subsecvenței [i - 2UB(i) + 1, i] a vectorului, unde UB(i) = poziția (indexată din dreapta cu 0) ultimului bit de 1 din reprezentarea binară a numărului i. Pentru a vizualiza mai ușor funcția, acestea sunt câteva valori:

UB(1) = 0
UB(2) = UB([10]) = 1
UB(3) = UB([11]) = 0
UB(4) = UB([100]) = 2
UB(6) = UB([110]) = 1
UB(600) = UB([1001011000]) = 3
UB(601) = UB([1001011001]) = 0

Calculați: UB() = UB([11000]) = 3

Se poate vedea ușor că UB(i) poate fi interpretat și ca numărul de zerouri terminale din reprezentarea binară a numărului i. Dacă considerăm reprezentarea binară a numărului nr drept fiind:

bitk...bit1bit0 = bit0 * 20 + bit1 * 21 + ... + bitk * 2k = 0 + 0 + ... + 1 * 2UB(nr) + bitUB(nr) + 1 * 2UB(nr) + 1 + ... + bitk * 2k = 2UB(nr) * (1 + bitUB(nr) + 1 * 2 + ... +bitk * 2(k - UB(nr))) = 2UB(nr) * (1 + M2), rezultă că nr este multiplu de 2UB(nr) și nu este multiplu de 2UB(nr) + 1, echivalent cu condiția inițială.


Determinarea numărului 2UB(x)

Numărul x poate fi scris drept (a1b), unde a este șirul de biți înaintea ultimului bit de 1, iar b este șirul de zerouri ce vine după ultimul 1 (de exemplu, 600 = (0)1001011000 ⇒ a600 = 100101, b600 = 000, iar semnul e pozitiv). Numărul -x va fi egal cu !(a1b) + 1, dar amintim că b este compus numai din zerouri. Astfel: -x = (!a0!b) + 1 = (!a0111...1) + 1 = (!a1000...0) = (!a1b) (de exemplu, -600 = (1)0110101000, iar semnul e negativ). Când aplicăm operatorul de conjuncție pe biți & asupra celor 2 numere rezultă: x&-x = (a1b)&(!a1b) = 000...01b = 000...01000...0 = 1000...0 = 2UB(x). Așadar, 2UB(x) = x&-x, ∀x ∈ ℕ*
Pe baza acestui număr sunt definite relațiile de rudenie între nodurile arborelui, în funcție de operația efectuată, despre care veți afla în articolele următoare.
