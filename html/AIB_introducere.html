Fie urmatoarea problema:

Se da un vector v (indexat de la 1) care contine n elemente, dupa care se dau m operatii care pot fi de 2 tipuri:
A) Adauga val la v[pos]; (Actualizare)
B) Afiseaza suma subsecventei [pos1, pos2] a vectorului; (Interogare)

O solutie consta in crearea unui vector suplimentar de sume partiale pentru raspuns in O(1) la interogare. Problema cu aceasta abordare este faptul ca actualizarea implica actualizarea sumelor partiale dupa pozitia modificata, ceea ce poate duce in cel mai rau caz la O(n), facand complexitatea totala O(n*m). Tot aceeasi complexitate obtinem daca renuntam la sume partiale pentru a actualiza in O(1) si raspundem in O(n) la interogare. Pentru o solutie optima de O(m*log n) vom putea folosi un AIB.

Ideea din spate

Un Arbore Indexat Binar este o structura de date dinamica, eficienta, usor de implementat, care ocupa putin spatiu si implementeaza in timp logaritmic actualizarea si interogarea pe un prefix/sufix. Acesta functioneaza dupa urmatorul principiu:

1. AIB[i]=v[i] daca i=M1, i!=M2
2. AIB[i]=v[i-1]+v[i] daca i=M2,i!=M4
3. AIB[i]=v[i-3]+v[i-2]+v[i-1]+v[i] daca i=M4,i!=M8
4. AIB[i]=v[i-7]+v[i-6]+v[i-5]+v[i-4]+v[i-3]+v[i-2]+v[i-1]+v[i] daca i=M8,i!=M16
...
k. AIB[i]=v[i-2(k-1)+1]+...+v[i-1]+v[i] daca i=M2(k-1),i!=M2k

Calculati: AIB[ ]=Σ(17,24);

Cu alte cuvinte, AIB[i] stocheaza suma subsecventei [i-2UB(i)+1,i] a vectorului, unde UB(i)=pozitia (indexata din dreapta cu 0) ultimului bit de 1 din reprezentarea binara a numarului i. Pentru a vizualiza mai usor functia, acestea sunt cateva valori:

UB(1)=0
UB(2)=UB([10])=1
UB(3)=UB([11])=0
UB(4)=UB([100])=2
UB(6)=UB([110])=1
UB(600)=UB([1001011000])=3
UB(601)=UB([1001011001])=0

Calculati: UB( )=UB([11000]=3;

Se poate vedea usor ca UB(i) poate fi interpretat si ca numarul de zerouri terminale din reprezentarea binara a numarului i. Daca consideram reprezentarea binara a numarului nr drept fiind:

bitk...bit1bit0 = bit0*20+bit1*21+...+bitk*2k = 0+...+1*2UB(nr)+bitUB(nr)+1*2(UB(nr)+1)+...+bitk*2k = 2UB(nr) * (1+bitUB(nr)+1*2+...+bitk*2(k-UB(nr))) = 2UB(nr) * (1+M2), rezulta faptul ca nr este multiplu de 2UB(nr) si nu este multiplu de 2(UB(nr)+1), echivalent cu conditia initiala.


Determinarea numarului 2UB(x)

Numarul x poate fi scris drept (a1b), unde a este sirul de biti inaintea ultimului bit de 1, iar b este sirul de zerouri ce vine dupa ultimul 1 (de exemplu, 600 = (0)1001011000 => a600=100101, b600=000, iar semnul e pozitiv). Numarul -x va fi egal cu !(a1b)+1, dar amintim faptul ca b este compus numai din zerouri. Astfel: -x = (!a0!b)+1 = (!a0111...1)+1 = (!a1000...0) = (!a1b) (de exemplu, -600 = (1)0110101000, iar semnul e negativ). Cand aplicam operatorul de conjunctie pe biti & asupra celor 2 numere rezulta: x&-x = (a1b)&(!a1b) = 000...01b = 000...01000...0 = 1000...0 = 2UB(x). Asadar, 2UB(x) = x&-x, ∀x∈ℕ*
Pe baza acestui numar sunt definite relatiile de rudenie intre nodurile arborelui in functie de modul in care acesta este inradacinat, despre care veti afla in articolele urmatoare.
