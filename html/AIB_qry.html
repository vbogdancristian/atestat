Funcția de interogare pe prefix

Pentru a calcula suma tuturor elementelor din subsecvența [p1,p2] avem: v[p1] + v[p1+1] + ... + v[p2-1] + v[p2] = (v[1] + v[2] + ... + v[p1-1] + v[p1] + v[p1+1] + ... + v[p2]) - (v[1] + v[2] + ... + v[p1-1]) ⇒ Σ(p1,p2) = Σ(1,p2) - Σ(1,p1-1). După cum sugerează și numele, funcția de interogare va returna pentru un index p dat suma tuturor elementelor din intervalul [1,p]. Pentru a efectua interogarea în O(log n) vom vizita anumite noduri ale AIB-ului astfel încât să formăm pas cu pas secvența dorită.

Întrebarea rămâne: cum putem identifica nodurile ce trebuie vizitate?

Vom reprezenta numarul p în baza 2 și vom șterge treptat fiecare bit setat începând din dreapta, până ajungem la primul. În alte cuvinte, aplicăm în mod repetat operația x = x - (x&-x), începând de la x = pos. Vom folosi drept reper vizualizarea arborelui indexat binar pentru a deduce formula folosită, după care îi vom demonstra validitatea matematic. Iată câteva exemple:

Σ(1, 1) = Σ(1, [1]) = AIB[1] = v[1];
Σ(1, 2) = Σ(1, [10]) = AIB[2] = v[1] + v[2];
Σ(1, 3) = Σ(1, [11]) = AIB[3] + AIB[2] = v[3] + v[1] + v[2];
Σ(1, 5) = Σ(1, [101]) = AIB[5] + AIB[4] = v[5] + v[1] + v[2] + v[3] + v[4];
Σ(1, 6) = Σ(1, [110]) = AIB[6] + AIB[4];
Σ(1, 9) = Σ(1, [1001]) = AIB[9] + AIB[8];
Σ(1, 24) = Σ(1, [11000]) = AIB[24] + AIB[16];
Σ(1, 31) = Σ(1, [11111]) = AIB[31] + AIB[30] + AIB[28] + AIB[24] + AIB[16];
Σ(1, 32) = Σ(1, [100000]) = AIB[32];

Σ(1, )=Σ(1, [1011100000]) = AIB[736] + AIB[704] + AIB[640] + AIB[512];

Reprezentarea clasică

Nodurile arborelui vor avea 2 valori: indexul unic și valoarea propriu-zisă (AIB[index]) pe care o putem ignora când reprezentăm grafic. Când spunem nodul a ne referim la nodul care are indexul egal cu a. Definim astfel arborele de interogare pe prefix:
Nodul y este părintele nodului x ⇔ y = x - (x&-x);
*Rădăcina arborelui va fi nodul imaginar 0, acesta nu corespunde unei subsecvențe din vector și are doar rolul de a uni mulțimile disjuncte create prin ignorarea nodurilor cu index mai mare decât n.

Observăm că dacă urcăm din nodul 11 către rădăcină și reunim intervalele nodurilor parcurse vom obține subsecvența [1,11], iar asta este adevărat pentru orice poziție datorită modului în care este definit părintele unui nod oarecare. Așadar, pentru a reconstitui suma elementelor din subsecvența [1,pos] trebuie să vizităm indecșii din șirul (x)n, x0 = pos, xi+1 = xi - (xi&-xi), singura precizare fiind că trebuie oprită căutarea când ajungem în nodul imaginar 0. Numărul de noduri vizitate este egal cu numărul de biți setați ai poziției căutate, iar aceasta poate avea maxim log2n astfel de biți, facând complexitatea funcției O(log n).

Reprezentarea prin segmente

Nodurile arborelui vor avea 2 valori: indexul unic și valoarea propriu-zisă. Când spunem nodul a ne referim la nodul care are indexul egal cu a. Spre deosebire de reprezentarea clasică, reprezentarea prin segmente este mai compactă, motiv pentru care am păstrat mai multe informații. Principiul este urmatorul: pe primul nivel se află nodurile care au lungimea intervalului (dr-st+1) egală cu 1, pe al doilea nivel se află nodurile cu lungimea intervalului egală cu 2, ..., pe al k-lea nivel se află nodurile cu lungimea intervalului egală cu 2k-1. Definim astfel arborele de interogare pe prefix:
Nodul y este "fratele stâng" nodului x ⇔ y = x - (x&-x).
Cu toate că nu există conceptul de frați "stângi" sau "drepți" atunci când discutăm despre arbori, ne putem gândi la muchiile arborelui în acest mod pentru a păstra aceeași figură la ambii arbori (de sufix și de prefix). Când avem o operație pe prefix vom parcurge "frații stângi", iar când avem o operație pe sufix vom parcurge părinții.

Este evident din reprezentare că pentru a acoperi intervalul original va trebui să alegem mereu "fratele stâng", adică nodul de unde se termină intervalul nodului curent ( x-(x&-x)+1 ). Așadar, pentru a reconstitui suma elementelor din subsecvența [1,pos] trebuie să vizităm indecșii din șirul (x)n, x0 = pos, xi+1 = xi - (xi&-xi), singura precizare fiind că trebuie oprită căutarea când nodul curent devine 0. Numărul de noduri vizitate este egal cu numărul de biți setați ai poziției căutate care poate avea maxim log2n astfel de biți, făcând complexitatea funcției O(log n).

Implementarea în C++

În stânga este codul funcției în C++ care implementeaza simplu și eficient parcurgerea nodurilor cheie discutată mai sus. Am păstrat comentariul din buclă în scheletul funcției pentru claritate.



sau selectează-l manual:

int query(int ind)
{
    int s=0;
    for(int i=ind;i>0;i-=(i&-i))
    {
        s+=aib[i];
    }
    return s;
}

De ce O(log n)?

Vom relua cele discutate: Funcția de interogare primește un număr x și îi șterge în fiecare iterație ultimul bit setat, până transformăm x în 0. Pentru a calcula complexitatea vrem să aflăm numărul maxim de biți pe care îi poate avea numărul x, așa că vom presupune că toți biții sunt setați. Dacă x are k biți înseamnă că acesta este mai mic decât orice număr care are k+1 biți (la fel cum în baza 10 orice număr de 2 cifre este mai mic decât orice număr de 3 cifre), iar cel mai mic număr de k+1 biți este 2k+1. În același timp este adevărat că orice număr de k biți este mai mare sau egal cu 2k (la fel cum orice număr de 2 cifre este mai mare sau egal cu 10). Așadar îl putem încadra pe x astfel: 2k ≤ x < 2k+1, inegalitatea se menține dacă logaritmăm în baza 2, ⇒ k ≤ log2x < k+1, ⇒ [log2x] = k = numărul de biți ai numărului x. Putem conclude astfel că numărul maxim de iterații pentru un input x oarecare este log2x.

Alte demonstrații🞃

Fie f:ℕ*→ℕ, f(x) = 2UB(x) = (x&-x); f(a1b) = 1b;
Fie șirul (x)n, x0 = pos, xi+1 = xi - f(xi)
f(0) = 0&-0 = 0&0 =0
Notăm interval(x) = intr(x) = [x-f(x)+1,x]
Vom demonstra faptul că intr(xi) ∪ intr(xi+1) = [xi+1 - f(xi+1) +1, xi]
intr(xi) = [xi - f(xi) +1, xi] = [xi+1 +1, xi];
intr(xi+1) = [xi+1 - f(xi+1) +1, xi+1];
intr(xi) ∪ intr(xi+1) = [xi+1 - f(xi+1) +1, xi+1] ∪ [xi+1 - f(xi+1) +1, xi] = [xi+1 - f(xi+1) +1, xi], adevărat deoarece lucrăm în ℕ ⇒ c.c.t.d.
Prin inducție se poate demonstra că pentru un oarecare k avem relația: intr(x0) ∪ intr(x1) ∪... ∪ intr(xk) = (notație) ∪(0,k) = [xk - f(xk) +1, x0]. Știind x[log2n] = 0, avem ∪(0,[log2n]) = [0-0+1,x0] = [1,x0].
