Functia de interogare pe prefix

Dupa cum sugereaza si numele, functia de interogare va returna pentru un index p dat suma tuturor elementelor din intervalul [1,p]. Pentru a calcula suma tuturor elementelor din subsecventa [p1,p2] avem: v[p1]+v[p1+1]+...+v[p2-1]+v[p2]=(v[1]+v[2]+...v[p1-1]+v[p1]+v[p1+1]+...+v[p2])-(v[1]+v[2]+...+v[p1-1])=> Σ(p1,p2)=Σ(1,p2)-Σ(1,p1-1). Pentru a efectua interogarea in O(log n) vom vizita anumite noduri ale AIB-ului astfel incat sa formam pas cu pas secventa dorita.

Intrebarea ramane: cum putem identifica nodurile ce trebuie vizitate?

Vom reprezenta numarul p in baza 2 si vom sterge treptat fiecare bit setat incepand din dreapta, pana ajungem la primul. In alte cuvinte, aplicam in mod repetat operatia x=x-(x&-x), incepand de la x=pos. Vom folosi drept reper vizualizarea arborelui indexat binar pentru a deduce formula folosita, dupa care ii vom demonstra validitatea matematic. Iata cateva exemple:

Σ(1,1)=Σ(1,[1])=AIB[1]=v[1];
Σ(1,2)=Σ(1,[10])=AIB[2]=v[1]+v[2];
Σ(1,3)=Σ(1,[11])=AIB[3]+AIB[2]=v[3]+v[1]+v[2];
Σ(1,5)=Σ(1,[101])=AIB[5]+AIB[4]=v[5]+v[1]+v[2]+v[3]+v[4];
Σ(1,6)=Σ(1,[110])=AIB[6]+AIB[4];
Σ(1,9)=Σ(1,[1001])=AIB[9]+AIB[8];
Σ(1,24)=Σ(1,[11000])=AIB[24]+AIB[16];
Σ(1,31)=Σ(1,[11111])=AIB[31]+AIB[30]+AIB[28]+AIB[24]+AIB[16];
Σ(1,32)=Σ(1,[100000])=AIB[32];

Σ(1,)=Σ(1,[1011100000])=AIB[736]+ AIB[704]+ AIB[640]+ AIB[512];

Reprezentarea grafica a unui AIB

In continuare puteti apasa pe reprezentarea AIB pe care o preferati:

Reprezentarea clasica

Nodurile arborelui vor avea 2 valori: indexul unic si valoarea propriu-zisa (AIB[index]) pe care o putem ignora cand reprezentam grafic. Cand spunem nodul a ne referim la nodul care are indexul egal cu a. Definim astfel arborele de interogare pe prefix:
Nodul y este parintele nodului x <=> y=x-(x&-x);
*Radacina arborelui va fi nodul imaginar 0, acesta nu ii corespunde unei subsecvente din vector si are doar rolul de a uni padurile disjuncte de arbori create prin ingorarea nodurilor cu index mai mare decat n.

Observam ca daca urcam din nodul 11 catre radacina si reunim intervalele nodurilor parcurse vom avea obtine subsecventa [1,11], iar asta este adevarat pentru orice pozitie datorita modului in care este definit parintele unui nod oarecare. Asadar, pentru a reconstitui suma elementelor din subsecventa [1,pos] trebuie sa vizitam indecsii din sirul (x)n, x0=pos, xi+1=xi-(xi&-xi), singura precizare fiind ca trebuie oprita cautarea cand ajungem in nodul imaginar 0. Numarul de noduri vizitate este egal cu numarul de biti setati ai pozitiei cautate, iar aceasta poate avea maxim log2n astfel de biti, facand complexitatea functiei O(log n).

Reprezentarea prin segmente

Nodurile arborelui vor avea 2 valori: indexul unic si valoarea propriu-zisa. Cand spunem nodul a ne referim la nodul care are indexul egal cu a. Spre deosebire de reprezentarea clasica, reprezentarea prin segmente este mai compacta, motiv pentru care am pastrat mai multe informatii. Principiul este urmatorul: pe primul nivel se afla nodurile care au lungimea intervalului (dr-st+1) egala cu 1, pe al doilea nivel se afla nodurile cu lungimea intervalului egala cu 2, ..., pe al k-lea nivel se afla nodurile cu lungimea intervalului egala cu 2k-1. Definim astfel arborele de interogare pe prefix:
Nodul y este "fratele stang" nodului x <=> y=x-(x&-x).
Cu toate ca nu exista conceptul de frati "stangi" sau "drepti" atunci cand discutam despre arbori, ne putem gandi la muchiile arborelui astfel pentru a pastra aceeasi figura la ambii arbori (de sufix si de prefix). Cand avem o operatie pe prefix vom parcurge "fratii stangi", iar cand avem o operatie pe sufix vom parcurge parintii.

Este evident din reprezentare faptul ca pentru a acoperi intervalul original va trebuii sa alegem mereu "fratele stang", adica nodul de unde se termina intervalul nodului curent (x-(x&-x)+1). Asadar, pentru a reconstitui suma elementelor din subsecventa [1,pos] trebuie sa vizitam indecsii din sirul (x)n, x0=pos, xi+1=xi-(xi&-xi), singura precizare fiind ca trebuie oprita cautarea cand nodul curent devine 0. Numarul de noduri vizitate este egal cu numarul de biti setati ai pozitiei cautate, iar aceasta poate avea maxim log2n astfel de biti, facand complexitatea functiei O(log n).

Implementarea in C++

In stanga este codul functiei in C++ care implementeaza simplu si eficient parcurgerea nodurilor cheie discutata mai sus. Comentariul din bucla nu este necesar, dar le-am pastrat in scheletul functiei pentru claritate.



sau selecteaza-l manual:

int query(int ind)
{
    int s=0;
    for(int i=ind;i>0;i-=(i&-i))
    {
        s+=aib[i];
    }
    return s;
}

De ce O(log n)?

Vom relua cele discutate: Functia de interogare primeste un numar x si ii sterge in fiecare iteratie ultimul bit setat, pana transformam x in 0. Pentru a calcula complexitatea vrem sa aflam numarul maxim de biti pe care ii poate avea numarul x, asa ca vom presupune ca toti bitii sunt setati. Daca x are k biti inseamna ca acesta este mai mic decat orice numar care are k+1 biti (la fel cum in baza 10 toate numerele de 2 cifre sunt mai mici decat orice numar de 3 cifre), iar cel mai mic numar de k+1 biti este 2k+1. In acelasi timp este adevarat ca orice numar de k biti este mai mare sau egal decat 2k (la fel cum orice numar de 2 cifre este mai mare sau egal ca 10). Asadar il putem incadra pe x astfel: 2k<=x.<2k+1, inegalitatea se mentine daca logaritmam in baza 2, => k<=log2x<k+1, => [log2x]= k = numarul de biti ai numarului x. Putem conclude astfel ca numarul maxim de iteratii pentru un input x oarecare este log2x.

intr(xi) = [xi-f(xi)+1,xi] = [xi+1+1,xi];
intr(xi+1) = [xi+1-f(xi+1)+1,xi+1];
intr(xi) ∪ intr(xi+1) = [xi+1-f(xi+1)+1,xi+1] ∪ [xi+1-f(xi+1)+1,xi] = [xi+1-f(xi+1)+1,xi], adevarat deoarece lucram in ℕ => c.c.t.d.
Prin inductie se poate demonstra faptul ca pentru un oarecare k avem relatia: intr(x0) ∪ intr(x1) ∪... ∪ intr(xk) = (notatie) ∪(0,k) = [xk - f(xk) +1, x0]. Stiind x[log2n] = 0, avem ∪(0,[log2n]) = [0-0+1,x0] = [1,x0].
