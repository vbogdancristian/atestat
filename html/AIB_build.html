*Pentru a ințelege acest articol este necesară familiarizarea cu structura unui AIB și funcția de actualizare.

Funcția de construire eficientă

Adesea atunci când vrem să creăm un AIB pe baza unui vector de lungime n vom apela funcția de actualizare de n ori pentru fiecare index.

for(int i=1;i<=n;i++)
{
	fin>>v[i];
	update(i,v[i]);
}

Dacă AIB-ul are deja valorile corespunzătoare unui alt vector w:

for(int i=1;i<=n;i++)
{
	fin>>v[i];
	update(i,v[i]-w[i]);
}

În cele mai multe cazuri când folosim AIB nu ne încurcă complexitatea de O(nlog n), dar se poate construi în timp liniar după urmatoarea recurență:

for(int i=1; i<=n; i++)
{
    AIB[i]+=v[i];///eventual -w[i]
    if(i+(i&-i)<=n)AIB[i+(i&-i)]+=AIB[i];
}

Indexul i trebuie adăugat la AIB[i], AIB[i + (i&-i)], AIB[i + (i&-i) + (i + (i&-i)&-(i + (i&-i)))] etc. În AIB[i] vor intra mai multe elemente ce se regasesc și în AIB[i + (i&-i)], acestea la rândul lor se regăsesc în AIB[i + (i&-i) + (i + (i&-i)&-(i + (i&-i)))], deci ar avea mai mult sens să adăugam la AIB[i + (i&-i)] suma tuturor pozițiilor din AIB[i] decât să îi luăm pe rând.

Recurența fiind liniară vom avea complexitatea finală O(n).
