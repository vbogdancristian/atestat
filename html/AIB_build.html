*Pentru a intelege acest articol este necesara familiarizarea cu structura unui AIB si functia de actualizare.

Functia de construire eficienta

Adesea atunci cand vrem sa cream un AIB pe baza unui vector de lungime n vom apela functia de actualizare de n ori pentru fiecare index.

for(int i=1;i<=n;i++)
{
	fin>>v[i];
	update(i,v[i]);
}

Daca AIB-ul are deja valorile corespunzatoare unui alt vector w:

for(int i=1;i<=n;i++)
{
	fin>>v[i];
	update(i,v[i]-w[i]);
}

In cele mai multe cazuri cand folosim AIB nu ne incurca complexitatea de O(nlog n), dar se poate construi in timp liniar dupa urmatoarea recurenta:

for(int i=1; i<=n; i++)
{
    AIB[i]+=v[i];///evenual -w[i] daca este cazul
    if(i+(i&-i)<=n)AIB[i+(i&-i)]+=AIB[i];
}

Indexul i trebuie adaugat la AIB[i], AIB[i+(i&-i)], AIB[i+(i&-i)+(i+(i&-i)&-(i+(i&-i)))] etc. In AIB[i] vor intra mai multe elemente ce se regasesc si AIB[i+(i&-i), acestea la randul lor se regasesc in AIB[i+(i&-i)+(i+(i&-i)&-(i+(i&-i)))], deci ar avea mai mult sens sa adaugam la AIB[i+(i&-i)] suma tuturor indecsilor determinati de AIB[i] decat sa ii luam pe rand.

Recurenta fiind liniara vom avea complexitatea finala O(n).
